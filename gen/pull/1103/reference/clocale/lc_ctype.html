macro
<clocale>

LC_CTYPE

#define LC_CTYPE unspecified

概要

文字の分類とマルチバイト文字の扱いに関するロケールカテゴリを指定するための定数。

<cctype>の文字種別判定関数、<cwctype>のワイド文字関数、およびstd::mbrtowc()などのマルチバイト文字変換関数の動作に影響する。

setlocale()関数のcategory引数として指定する。値はint型の処理系定義の定数式であり、各カテゴリのマクロは互いに異なる値をもつ。

例

#include <clocale>
#include <iostream>

int main()
{
  // 文字種別・マルチバイト変換のロケールをCロケールに設定する
  std::cout << std::setlocale(LC_CTYPE, "C") << std::endl;
}
