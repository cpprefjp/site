std::simd::imag(C++26)

namespace std::simd {
  template<simd-complex V>
  constexpr rebind_t<simd-complex-value-type<V>, V> imag(const V& v) noexcept; // C++26
}

概要

要素型がstd::complex<T>のbasic_vecについて、各要素の虚部を取り出し、実数型Tを要素とするbasic_vecとして返す。

制約simd-complexは、Vが要素型std::complex<T>のbasic_vecであることを表す説明専用のコンセプトである。simd-complex-value-type<V>はVの要素型std::complex<T>におけるT（実数型）を表す。戻り値の型はVの要素数はそのままに要素型をTとしたbasic_vecとなる。

戻り値

各要素i（0以上V::size()未満）について、v[i]に<complex>のimagを適用した結果で初期化されたbasic_vecオブジェクトを返す。

例

#include <simd>
#include <complex>
#include <print>

namespace simd = std::simd;

int main()
{
  // 各要素が複素数のデータ並列型
  simd::vec<std::complex<float>, 2> v{
    [](int i) { return std::complex<float>(i + 1.0f, i + 0.5f); }
  };  // {(1, 0.5), (2, 1.5)}

  // 各要素の虚部を取り出す
  simd::vec<float, 2> im = simd::imag(v);

  for (std::size_t i = 0; i < im.size(); ++i)
    std::print("{} ", im[i]);
  std::println("");
}

出力例

0.5 1.5
